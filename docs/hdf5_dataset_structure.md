# HDF5 Dataset Structure

This document outlines the hierarchical structure of the HDF5 datasets generated by the `HDF5Recorder` and provides Python code examples on how to read and access each specific value using the `h5py` library.

## Initial Setup: Opening the File

To access any data, you first need to open the HDF5 file in read mode (`'r'`):

```python
import h5py
import numpy as np
import json

# Open the HDF5 dataset file
f = h5py.File("path/to/your/dataset.hdf5", "r")
```

---

## 1. The Root Data Group: `data`

Everything is stored under a single top-level group called `data`. This group contains global attributes about the recording environment and setup.

### Structure
* **Group:** `data`
  * **Attributes:** `robot`, `env`, `fps`, `task`, `external_camera`, `wrist_camera`

### How to access:

```python
# Access the main data group
data_group = f["data"]

# Accessing global attributes
robot_name = data_group.attrs["robot"]
env_name = data_group.attrs["env"]
fps = data_group.attrs["fps"]
task = data_group.attrs["task"]
ext_cam_name = data_group.attrs["external_camera"]
wrist_cam_name = data_group.attrs["wrist_camera"]

print(f"Task: {task} recorded at {fps} FPS on {robot_name}")
```

---

## 2. Episode Groups: `demo_<episode_number>`

Inside the `data` group, every successful demonstration is saved as a separate subgroup named `demo_0`, `demo_1`, etc. Each episode group contains episode-specific metadata (attributes) and datasets.

### Structure
* **Group:** `demo_<episode_number>`
  * **Attributes:** `object_type`, `object_name`, `object_size_parameters_m`, `object_mass_kg`, `object_initial_position_m`, `object_initial_quat_wxyz`, `num_samples`, `language_instruction`, `randomization_seed`, `phase_id_to_name`, `gripper_convention`, `recorder_version`

### How to access:

```python
# Access a specific episode (e.g., demo_0)
episode_name = "demo_0"
episode_group = data_group[episode_name]

# Alternatively, iterate through all episodes:
# for ep_name, ep_group in data_group.items():
#     print(f"Reading {ep_name}...")

# Accessing episode attributes
obj_type = episode_group.attrs["object_type"]
obj_name = episode_group.attrs["object_name"]
obj_size = episode_group.attrs["object_size_parameters_m"] # Numpy array
obj_mass = episode_group.attrs["object_mass_kg"]
obj_pos = episode_group.attrs["object_initial_position_m"] # Numpy array
obj_quat = episode_group.attrs["object_initial_quat_wxyz"] # Numpy array
num_samples = episode_group.attrs["num_samples"]
instruction = episode_group.attrs["language_instruction"]
seed = episode_group.attrs["randomization_seed"]
gripper_conv = episode_group.attrs["gripper_convention"]
version = episode_group.attrs["recorder_version"]

# Phase names are saved as a JSON string, so we load them back to a Python list/tuple
phase_names_str = episode_group.attrs["phase_id_to_name"]
phase_names = json.loads(phase_names_str) 
```

---

## 3. Episode Datasets

Directly under each `demo_<episode_number>` group, there are several datasets tracking the robot's actions, simulation states, and task progress over time.

### Structure
* **Datasets (Directly under `demo_X`):** 
  * `actions`, `actions_openvla`, `states`, `robot_states`, `phase_id`, `timestamp`, `gripper_command`, `rewards`, `dones`

### How to access:
*Note: Use `[:]` at the end of the dataset call to load the entire HDF5 dataset into memory as a NumPy array.*

```python
# --- Actions ---
# Shape: (num_samples, 7)
actions = episode_group["actions"][:] 
actions_openvla = episode_group["actions_openvla"][:] 
gripper_cmd = episode_group["gripper_command"][:] # Shape: (num_samples, 1)

# --- States ---
sim_states = episode_group["states"][:]           # Flattened simulation state
robot_states = episode_group["robot_states"][:]   # [gripper qpos, eef xyz, eef quat]

# --- Temporal & Logic ---
phase_ids = episode_group["phase_id"][:]          # uint8 array of phase indices
timestamps = episode_group["timestamp"][:]        # float64 array of time in seconds
rewards = episode_group["rewards"][:]             # uint8 array, 1 at the end if successful
dones = episode_group["dones"][:]                 # uint8 array, 1 at the end of episode
```

---

## 4. Observations Group: `obs`

Inside each `demo_<episode_number>` group, there is an `obs` subgroup that contains all the rich sensor data, including images and proprioception, recorded at each frame.

### Structure
* **Group:** `obs`
  * **Datasets:** `agentview_rgb`, `wrist_rgb`, `joint_states`, `gripper_states`, `ee_states`, `ee_pos`, `ee_ori`, `previous_action`

### How to access:

```python
# Access the observations subgroup
obs_group = episode_group["obs"]

# --- Images (Cameras) ---
# Shape: (num_samples, height, width, 3), dtype: uint8
agentview_images = obs_group["agentview_rgb"][:]
wrist_images = obs_group["wrist_rgb"][:]

# --- Proprioception ---
joint_states = obs_group["joint_states"][:]       # (num_samples, 6)
gripper_states = obs_group["gripper_states"][:]   # (num_samples, 2) - physical joint positions

# --- End-Effector (EE) Tracking ---
ee_states = obs_group["ee_states"][:]             # (num_samples, 6) - pos + axis-angle
ee_pos = obs_group["ee_pos"][:]                   # (num_samples, 3) - x, y, z
ee_ori = obs_group["ee_ori"][:]                   # (num_samples, 3) - axis-angle representation

# --- Memory/Context ---
# The action executed in the previous step (useful for autoregressive models)
previous_actions = obs_group["previous_action"][:] 
```

## Closing the File
Always remember to close the HDF5 file when you are done extracting the data to free up memory and prevent file lock issues.

```python
f.close()
```
